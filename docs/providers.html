Providers

Four LLM providers, all implementing the ChatModel protocol with sync, async, and streaming support.

ChatModel Protocol

All providers implement this interface:

MethodDescription
generate(messages, tools?, temperature?, max_tokens?)Sync completion
agenerate(messages, ...)Async completion
stream(messages, ...)Sync streaming
astream(messages, ...)Async streaming
bind_tools(tools)Pre-bind tools for repeated calls

OpenAI

python
from infy.providers.openai import OpenAIChat
from infy.messages import HumanMessage, SystemMessage

model = OpenAIChat("gpt-4o")

# Basic generation
result = model.generate([
    SystemMessage(content="You are helpful."),
    HumanMessage(content="What is the capital of France?"),
])
print(result.text)

# With streaming
for chunk in model.stream([HumanMessage(content="Tell me a joke")]):
    print(chunk.text, end="", flush=True)

# Async
result = await model.agenerate([HumanMessage(content="Hello!")])

# Custom API key and base URL
model = OpenAIChat(
    model_name="gpt-4o",
    api_key="sk-...",
    base_url="https://api.openai.com/v1",
)

Tool Calling

All providers support tool calling with the same API:

python
from infy.providers.openai import OpenAIChat
from infy.messages import HumanMessage
from infy.tools import ToolSchema

model = OpenAIChat("gpt-4o")

# Define tools
tools = [
    ToolSchema(
        name="search",
        description="Search the web",
        parameters={"type": "object", "properties": {"query": {"type": "string"}}, "required": ["query"]},
    )
]

# Generate with tools
result = model.generate(
    [HumanMessage(content="Search for infy")],
    tools=tools,
)
print(result.tool_calls)  # [ToolCall(name='search', args={'query': 'infy'}, ...)]

# Bind tools for repeated use
bound = model.bind_tools(tools)
result = bound.generate([HumanMessage(content="Search for infy")])

Complete Example

python
from infy import tool, create_agent
from infy.providers.openai import OpenAIChat
from infy.providers.anthropic import AnthropicChat
from infy.providers.ollama import OllamaChat

@tool
def get_weather(city: str) -> str:
    """Get weather for a city."""
    return f"Weather in {city}: sunny, 72F"

# Use any provider with the same agent code
for model in [
    OpenAIChat("gpt-4o"),
    AnthropicChat("claude-sonnet-4-20250514"),
    OllamaChat("llama3.1"),
]:
    agent = create_agent(model, tools=[get_weather])
    result = agent("What's the weather in SF?")
    print(f"{model.model_name}: {result.response.text}")
