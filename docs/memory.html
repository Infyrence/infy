API Reference

Memory

Manage conversation history with three strategies. All implement the Memory protocol.

Memory Protocol

MethodDescription
load_memory_variables()Return current memory as a list of messages
save_context(input, output)Store an input/output pair
clear()Reset all memory

BufferMemory

Keeps all messages in memory. No eviction. Simplest option:

python
from infy.memory import BufferMemory
from infy.messages import HumanMessage, AIMessage

mem = BufferMemory(system_prompt="You are helpful.")

mem.save_context(
    HumanMessage(content="Hi, my name is Alice"),
    AIMessage(content="Hello Alice! How can I help?"),
)
mem.save_context(
    HumanMessage(content="What's the weather?"),
    AIMessage(content="It's sunny today!"),
)

messages = mem.load_memory_variables()
print(len(messages))  # 3 (system + 2 exchanges = 5, but save_context adds 2 per call)
print(messages[0].type)  # "system"
print(messages[1].text)  # "Hi, my name is Alice"

print(mem.message_count)  # 4

mem.clear()
print(mem.message_count)  # 0

TokenLimitedMemory

Keeps messages within a token budget by trimming the oldest. Uses Rust-accelerated token counting when available:

python
from infy.memory import TokenLimitedMemory
from infy.messages import HumanMessage, AIMessage

mem = TokenLimitedMemory(max_tokens=100)

# Add messages until budget is exceeded
for i in range(20):
    mem.save_context(
        HumanMessage(content=f"Message {i}: " + "x" * 50),
        AIMessage(content=f"Response {i}: " + "y" * 50),
    )

# Only recent messages that fit in the budget are returned
messages = mem.load_memory_variables()
print(f"Kept {len(messages)} of {mem.message_count} messages")
print(f"Estimated tokens: {mem.estimated_tokens}")

How It Works

  1. Counts tokens for each message using infy.tokens.count_tokens
  2. Walks backwards from the most recent message
  3. Keeps as many messages as fit within max_tokens
  4. Older messages are dropped (not summarized)

SummaryMemory

Summarizes old messages using an LLM. Keeps a running summary + recent messages in full:

python
from infy.memory import SummaryMemory
from infy.providers.openai import OpenAIChat

mem = SummaryMemory(
    model=OpenAIChat("gpt-4o"),
    buffer_size=6,  # Keep last 6 messages in full
)

# Add many messages
for i in range(20):
    mem.save_context(
        HumanMessage(content=f"Tell me about topic {i}"),
        AIMessage(content=f"Topic {i} is interesting because..."),
    )

# Memory includes: summary + recent messages
messages = mem.load_memory_variables()
print(f"Summary: {mem.summary[:100]}...")
print(f"Recent messages: {len(messages)}")

How Summarization Works

  1. When messages > buffer_size, the oldest messages are summarized
  2. The LLM generates a 2-3 sentence summary
  3. The summary replaces the old messages in memory
  4. Subsequent summaries incorporate previous summaries
If no model is provided to SummaryMemory, it falls back to simple trimming (like TokenLimitedMemory).

Comparison

StrategyMemory UsageQualitySpeedBest For
BufferMemoryGrows unboundedPerfect recallInstantShort conversations
TokenLimitedMemoryBounded by tokensDrops old contextFast (Rust)Long conversations, known budget
SummaryMemoryBounded by bufferCompressed recallSlower (LLM call)Very long conversations

Complete Example

python
from infy import tool, create_agent
from infy.memory import BufferMemory
from infy.messages import HumanMessage, AIMessage
from infy.providers.openai import OpenAIChat

@tool
def get_weather(city: str) -> str:
    """Get weather for a city."""
    return f"Weather in {city}: sunny, 72F"

model = OpenAIChat("gpt-4o")
memory = BufferMemory(system_prompt="You are a helpful weather assistant.")

agent = create_agent(
    model,
    tools=[get_weather],
    system_prompt="You are a helpful weather assistant.",
)

# Conversation loop
def chat(user_input: str) -> str:
    # Load memory
    history = memory.load_memory_variables()

    # Run agent
    result = agent(history + [HumanMessage(content=user_input)])

    # Save to memory
    memory.save_context(
        HumanMessage(content=user_input),
        result.response,
    )

    return result.response.text

# Multi-turn conversation
print(chat("Hi, I'm Bob"))
print(chat("What's the weather in SF?"))
print(chat("And in NYC?"))  # Agent remembers Bob and previous context
