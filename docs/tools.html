Tools

Decorate a function with @tool and it's ready for any LLM. Schema is auto-generated from type hints and docstrings.

@tool Decorator

The simplest way to create a tool. Works with both sync and async functions:

python
from infy import tool

@tool
def get_weather(city: str) -> str:
    """Get the current weather for a city."""
    return f"Weather in {city}: sunny, 72F"

@tool
async def fetch_data(url: str) -> str:
    """Fetch data from a URL."""
    import httpx
    async with httpx.AsyncClient() as client:
        resp = await client.get(url)
        return resp.text

Custom Name

Override the tool name with the name parameter:

python
@tool(name="weather_lookup")
def get_weather(city: str) -> str:
    """Get the current weather for a city."""
    return f"Weather in {city}: sunny"

Auto Schema Generation

The decorator inspects your function's type hints and docstring to build a JSON schema:

python
from infy import tool

@tool
def search_web(query: str, max_results: int = 5) -> str:
    """Search the web for information."""
    return f"Results for: {query}"

# View the generated schema
import json
print(json.dumps(search_web.to_schema().parameters, indent=2))
# {
#   "type": "object",
#   "properties": {
#     "query": {"type": "string", "description": ""},
#     "max_results": {"type": "integer", "default": 5, "description": ""}
#   },
#   "required": ["query"]
# }

# Full schema as sent to the LLM
print(json.dumps(search_web.to_schema().to_dict(), indent=2))
# {
#   "type": "function",
#   "function": {
#     "name": "search_web",
#     "description": "Search the web for information.",
#     "parameters": { ... }
#   }
# }

Tool Invocation

Tools can be invoked directly or used with agents:

python
from infy import tool

@tool
def calculator(expression: str) -> str:
    """Evaluate a math expression."""
    return str(eval(expression))

# Invoke with a string (JSON-parsed)
result = calculator.invoke('{"expression": "2 + 2"}')
print(result)  # "4"

# Invoke with a dict
result = calculator.invoke({"expression": "10 * 5"})
print(result)  # "50"

# Async invocation
result = await calculator.ainvoke({"expression": "3 + 7"})
print(result)  # "10"

Validation

The tool validates required parameters and applies defaults:

python
from infy import tool

@tool
def create_user(name: str, age: int, role: str = "viewer") -> str:
    """Create a new user account."""
    return f"Created {name} (age {age}, role {role})"

# Missing required param raises ValueError
try:
    create_user.invoke({"name": "Alice"})
except ValueError as e:
    print(e)  # "Missing required argument: age"

# Default values are applied
result = create_user.invoke({"name": "Alice", "age": 30})
print(result)  # "Created Alice (age 30, role viewer)"

ToolSchema

ToolSchema is the JSON representation sent to the LLM. Tools generate it automatically:

python
from infy.tools import ToolSchema

schema = ToolSchema(
    name="search",
    description="Search the web",
    parameters={
        "type": "object",
        "properties": {
            "query": {"type": "string"}
        },
        "required": ["query"]
    }
)

# Convert to LLM-ready dict
d = schema.to_dict()
print(d)
# {'type': 'function', 'function': {'name': 'search', ...}}

Complete Example

python
from infy import tool, create_agent
from infy.providers.openai import OpenAIChat

@tool
def search(query: str) -> str:
    """Search the web for information."""
    return f"Results for '{query}': infy is a fast LLM framework."

@tool
def calculator(expression: str) -> str:
    """Evaluate a mathematical expression."""
    return str(eval(expression))

@tool
def read_file(path: str) -> str:
    """Read the contents of a file."""
    with open(path) as f:
        return f.read()

# Create an agent with tools
agent = create_agent(
    OpenAIChat("gpt-4o"),
    tools=[search, calculator, read_file],
    system_prompt="You are a helpful assistant. Use tools when needed.",
)

result = agent("What is 2+2? Also search for 'infy'")
print(result.response.text)
print(f"Tool calls: {result.tool_calls_made}")
