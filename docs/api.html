API Reference

API Reference

Alphabetical listing of all public exports from infy. Version 0.1.0.

All imports are from the top-level infy package unless noted. Example: from infy import AIMessage.

Core

Runnable Protocol

Module: infy.core

The core protocol. Every composable unit implements this. Methods: invoke, ainvoke, stream, astream, __or__, __ror__.

from infy.core import Runnable

class MyRunnable:
    def invoke(self, input, ctx=None): ...
    async def ainvoke(self, input, ctx=None): ...
    def stream(self, input, ctx=None): ...
    async def astream(self, input, ctx=None): ...
    def __or__(self, other): ...
    def __ror__(self, other): ...

Sequence Class

Module: infy.core

A chain of runnables executed in order. Created by the | pipe operator.

from infy import Sequence, Lambda

chain = Sequence([Lambda(str.upper), Lambda(str.strip)])
result = chain.invoke("  hello  ")  # "HELLO"

Fields: steps: list[Runnable]

Parallel Class

Module: infy.core

Execute multiple runnables concurrently on the same input. Returns a dict of results.

from infy import Parallel, Lambda

p = Parallel({"upper": Lambda(str.upper), "len": Lambda(len)})
result = p.invoke("hello")  # {'upper': 'HELLO', 'len': 5}

Fields: steps: dict[str, Runnable]

Lambda Class

Module: infy.core

Wrap a sync function as a Runnable.

from infy import Lambda
r = Lambda(lambda x: x * 2)
print(r.invoke(5))  # 10

Fields: func: Callable

AsyncLambda Class

Module: infy.core

Wrap an async function as a Runnable.

from infy import AsyncLambda
r = AsyncLambda(lambda x: x * 2)
result = await r.ainvoke(5)  # 10

Fields: func: Callable

Context Class

Module: infy.core

Execution context carrying tags, metadata, and concurrency settings.

from infy.core import Context
ctx = Context(tags=["prod"], metadata={"user": "123"}, max_concurrency=4)
merged = ctx.merge(other_ctx)

Fields: tags: list[str], metadata: dict[str, Any], max_concurrency: int | None

coerce Function

Module: infy.core

Convert a callable, dict, or Tool to a Runnable.

from infy.core import coerce
r = coerce(lambda x: x + 1)  # → Lambda
r = coerce({"a": fn_a, "b": fn_b})  # → Parallel
r = coerce(my_tool)  # → Runnable wrapper

Messages

HumanMessage Class

Module: infy.messages

User input message.

from infy import HumanMessage
msg = HumanMessage(content="Hello!")
print(msg.text)  # "Hello!"
print(msg.type)  # "human"

Fields: content: str | list[ContentBlock], name: str | None, id: str | None

AIMessage Class

Module: infy.messages

Model output. May contain text, tool calls, or both.

from infy import AIMessage, ToolCall, UsageMetadata
msg = AIMessage(
    content="Hello!",
    tool_calls=[ToolCall(name="search", args={"q": "test"}, id="c1")],
    usage=UsageMetadata(input_tokens=10, output_tokens=5),
)
print(msg.text)  # "Hello!"
print(msg.has_tool_calls)  # True

Fields: content, tool_calls: list[ToolCall], usage: UsageMetadata | None, response_metadata: dict

SystemMessage Class

Module: infy.messages

System instruction for the model.

from infy import SystemMessage
msg = SystemMessage(content="You are helpful.")
print(msg.text)  # "You are helpful."

Fields: content: str | list[ContentBlock], name: str | None

ToolMessage Class

Module: infy.messages

Result of a tool execution.

from infy import ToolMessage
msg = ToolMessage(content="sunny, 72F", tool_call_id="c1")
print(msg.type)  # "tool"

Fields: content: str, tool_call_id: str, name: str | None, artifact: Any, status: str

Message Type

Module: infy.messages

Union type: HumanMessage | AIMessage | SystemMessage | ToolMessage

AIMessageChunk Class

Module: infy.messages

Streaming chunk. Merges additively via __add__.

from infy import AIMessageChunk
c1 = AIMessageChunk(content="Hello")
c2 = AIMessageChunk(content=" world")
full = c1 + c2  # "Hello world"
msg = full.materialize()  # → AIMessage

Fields: content, tool_call_chunks: list[ToolCallChunk], usage: UsageMetadata | None

ToolCall Class

Module: infy.messages

A tool call requested by the model.

from infy import ToolCall
tc = ToolCall(name="search", args={"query": "test"}, id="c1")
print(tc.to_dict())  # {'name': 'search', 'args': {...}, 'id': 'c1'}

Fields: name: str, args: dict[str, Any], id: str

ToolCallChunk Class

Module: infy.messages

A streaming chunk of a tool call. Merges by index.

Fields: name: str | None, args: str, id: str | None, index: int

UsageMetadata Class

Module: infy.messages

Token usage from an API call. total_tokens is auto-calculated.

from infy import UsageMetadata
u = UsageMetadata(input_tokens=100, output_tokens=50)
print(u.total_tokens)  # 150

Fields: input_tokens: int, output_tokens: int, total_tokens: int

Content Blocks

Module: infy.messages

TextBlock, ImageBlock, ToolCallBlock, ToolResultBlock — typed content for multimodal messages.

from infy.messages import TextBlock, ImageBlock
tb = TextBlock(text="Hello")
ib = ImageBlock(url="https://...", mime_type="image/jpeg")

Tools

tool Decorator

Module: infy.tools

Decorator to turn a function into a Tool. Works with sync and async functions.

from infy import tool

@tool
def search(query: str) -> str:
    """Search the web."""
    return "results"

@tool(name="custom_name")
def my_func(x: int) -> int:
    """A custom-named tool."""
    return x * 2

Tool Class

Module: infy.tools

A callable tool with auto-generated schema.

from infy.tools import Tool
t = Tool(name="search", description="Search", func=my_func, args_schema={...})
result = t.invoke({"query": "test"})
result = await t.ainvoke({"query": "test"})
schema = t.to_schema()  # → ToolSchema

Fields: name: str, description: str, func: Callable, args_schema: dict

ToolSchema Class

Module: infy.models

JSON Schema for a tool, as sent to the LLM.

from infy.models import ToolSchema
s = ToolSchema(name="search", description="Search", parameters={...})
d = s.to_dict()  # LLM-ready dict

Fields: name: str, description: str, parameters: dict

Agents

create_agent Function

Module: infy.agents

Create a sync agent. Returns a callable.

from infy import create_agent
agent = create_agent(model, tools=[...], system_prompt="...", max_iterations=10)
result = agent("Hello")  # → AgentResult

Params: model: ChatModel, tools: list[Tool] | None, system_prompt: str | None, max_iterations: int = 10, parallel_tools: bool = True

create_async_agent Function

Module: infy.agents

Create an async agent. Returns a coroutine.

from infy import create_async_agent
agent = create_async_agent(model, tools=[...])
result = await agent("Hello")  # → AgentResult

AgentResult Class

Module: infy.agents

The output of an agent run.

from infy.agents import AgentResult
# Fields: messages, response, iterations, tool_calls_made

Fields: messages: list[Message], response: AIMessage, iterations: int, tool_calls_made: int

Memory

Memory Protocol

Module: infy.memory

Interface: load_memory_variables(), save_context(input, output), clear()

BufferMemory Class

Module: infy.memory

Keeps all messages. No eviction.

from infy import BufferMemory
mem = BufferMemory(system_prompt="You are helpful.")
mem.save_context(HumanMessage(content="Hi"), AIMessage(content="Hello!"))
messages = mem.load_memory_variables()

Fields: messages: list[Message], system_prompt: str | None

TokenLimitedMemory Class

Module: infy.memory

Keeps messages within a token budget. Uses Rust token counting.

from infy import TokenLimitedMemory
mem = TokenLimitedMemory(max_tokens=4000)
mem.save_context(...)
messages = mem.load_memory_variables()  # only fits within budget

Fields: max_tokens: int, messages: list[Message], system_prompt: str | None

SummaryMemory Class

Module: infy.memory

Summarizes old messages using an LLM. Keeps recent messages in full.

from infy import SummaryMemory
mem = SummaryMemory(model=llm, buffer_size=6)
mem.save_context(...)
messages = mem.load_memory_variables()

Fields: model: Any, buffer_size: int, messages: list[Message], summary: str, system_prompt: str | None

RAG

Document Class

Module: infy.documents

A piece of content with metadata. The unit of retrieval.

from infy import Document
doc = Document(page_content="Hello", metadata={"source": "test.md"})
print(doc.id)  # auto UUID
print(doc.to_dict())

Fields: page_content: str, metadata: dict, id: str

DocumentChunk Class

Module: infy.documents

A chunk of a document with position info.

Fields: document: Document, chunk_index: int, total_chunks: int, start_char: int, end_char: int, id: str

RAGChain Class

Module: infy.rag

Complete RAG pipeline: retrieve → build prompt → generate.

from infy import RAGChain
rag = RAGChain(retriever=ret, model=llm, k=4)
result = rag.invoke("What is infy?")
print(result.response, result.source_documents)

Fields: retriever, model, system_prompt: str, k: int, include_sources: bool

RAGResult Class

Module: infy.rag

Fields: response: str, source_documents: list[Document], query: str, usage: dict | None

Graph

StateGraph Class

Module: infy.graph

Build a stateful graph by adding nodes and edges.

from infy.graph import StateGraph, START, END
g = StateGraph(State)
g.add_node("agent", agent_fn)
g.add_edge(START, "agent")
app = g.compile()

CompiledGraph Class

Module: infy.graph

Executable graph with checkpoint support.

result = app.invoke(input, config={...})
state = app.get_state(config)
new_config = app.update_state(config, values)

InMemorySaver Class

Module: infy.graph

In-memory checkpoint storage. Implements BaseCheckpointSaver.

from infy.graph import InMemorySaver
saver = InMemorySaver()
app = graph.compile(checkpointer=saver)

Channels

Module: infy.graph

LastValue — single value per key. BinOp — reducer accumulation. Topic — list accumulation.

from infy.graph import LastValue, BinOp, Topic

Graph Types

Module: infy.graph

START, END — special node names. Send — fan-out dispatch. Command — navigation/update. Interrupt — pause for HITL. StateSnapshot — read-only state view.

from infy.graph import START, END, Send, Command, Interrupt, StateSnapshot

create_graph_agent Function

Module: infy.graph

Create a stateful graph-based agent with checkpointing.

from infy.graph import create_graph_agent, InMemorySaver
agent = create_graph_agent(
    model, tools=[...], checkpointer=InMemorySaver(),
    interrupt_before=["tools"],
)
result = agent.invoke(input, config={...})

Streaming

stream_text Function

Module: infy.streaming

Consume a stream and return the full accumulated text.

from infy.streaming import stream_text
text = stream_text(model.stream([HumanMessage(content="Hi")]))

stream_to_list Function

Module: infy.streaming

Consume a stream into a list of chunks.

from infy.streaming import stream_to_list
chunks = stream_to_list(model.stream([HumanMessage(content="Hi")]))

merge_chunks Function

Module: infy.streaming

Merge a list of streaming chunks into one accumulated result.

from infy.streaming import merge_chunks
full = merge_chunks(chunk_list)

tee Function

Module: infy.streaming

Split a stream into n independent copies.

from infy.streaming import tee
s1, s2 = tee(stream, 2)

Tracing

Tracer Protocol

Module: infy.tracing

Implement on_start, on_end, on_error for any observability backend.

NoOpTracer Class

Module: infy.tracing

Default tracer. Does nothing. Zero overhead.

traced Decorator

Module: infy.tracing

Decorator to trace function execution. Works with sync and async.

from infy.tracing import traced

@traced
def my_func(x): return x

@traced(name="custom")
async def my_async(x): return x

Global Functions

Module: infy.tracing

set_tracer(tracer) — set global tracer. get_tracer() — get current tracer.

Parsers

StrParser Class

Module: infy.parsers

Extract text content from a message or string.

from infy.parsers import StrParser
p = StrParser()

JsonParser Class

Module: infy.parsers

Parse JSON from LLM output. Supports markdown code blocks and partial parsing. Uses Rust core when available.

from infy.parsers import JsonParser
p = JsonParser()

Tokens

count_tokens Function

Module: infy.tokens

Fast token count approximation. Uses Rust core when available.

from infy.tokens import count_tokens
n = count_tokens("Hello world")  # ~2

count_tokens_batch Function

Module: infy.tokens

Count tokens for multiple texts.

from infy.tokens import count_tokens_batch
counts = count_tokens_batch(["Hello", "World"])  # [1, 1]

Similarity

cosine_similarity Function

Module: infy.similarity

Cosine similarity between two vectors. Uses Rust SIMD (AVX2) when available.

from infy.similarity import cosine_similarity
score = cosine_similarity([1, 0, 0], [1, 0, 0])  # 1.0

batch_cosine_similarity Function

Module: infy.similarity

Find most similar documents. Returns list[tuple[int, float]] sorted by score descending.

from infy.similarity import batch_cosine_similarity
results = batch_cosine_similarity(query_vec, doc_vectors, top_k=5)

Text Splitters

Split text by character count with overlap.

Module: infy.text_splitter

Recursively split using a hierarchy of separators. Preserves structure better.

from infy.text_splitter import RecursiveTextSplitter
