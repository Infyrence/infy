Getting Started

Go from zero to a working agent in under 5 minutes.

Installation

Install the core package with zero dependencies:

pip install infy

Add a provider:

# OpenAI
pip install infy[openai]

# Anthropic
pip install infy[anthropic]

# Gemini
pip install infy[gemini]

# Ollama (local models)
pip install infy[ollama]

# Everything
pip install infy[all]
infy requires Python 3.10 or later. The core package has zero dependencies — providers are installed as extras.

Quick Start

First Chain

Compose runnables with the pipe operator |:

python
from infy import Lambda, JsonParser
from infy.providers.openai import OpenAIChat

model = OpenAIChat("gpt-4o")
parser = JsonParser()

# Pipe operator: prompt | model | parser
chain = (
    Lambda(lambda q: f"Answer in JSON: {q}")
    | model
    | parser
)

result = chain.invoke("What is the capital of France?")
print(result)  # {"answer": "Paris", ...}

First Tool

Decorate any function with @tool:

python
from infy import tool

@tool
def get_weather(city: str) -> str:
    """Get the current weather for a city."""
    return f"The weather in {city} is sunny, 72F."

# The tool auto-generates a JSON schema
print(get_weather.to_schema().to_dict())
# {'type': 'function', 'function': {'name': 'get_weather', ...}}

# Invoke it directly
result = get_weather.invoke("San Francisco")
print(result)  # "The weather in San Francisco is sunny, 72F."

First Agent

Create an agent that can use tools in a loop:

python
from infy import tool, create_agent
from infy.providers.openai import OpenAIChat

@tool
def calculator(expression: str) -> str:
    """Evaluate a math expression."""
    return str(eval(expression))

@tool
def search(query: str) -> str:
    """Search the web for information."""
    return f"Results for: {query}"

agent = create_agent(
    OpenAIChat("gpt-4o"),
    tools=[calculator, search],
    system_prompt="You are a helpful assistant. Use tools when needed.",
    max_iterations=10,
)

result = agent("What is 42 * 17 + search for 'python release date'?")
print(result.response.text)
print(f"Tool calls made: {result.tool_calls_made}")
print(f"Iterations: {result.iterations}")

First Graph

Build a stateful graph with conditional routing:

python
from typing import TypedDict, Annotated
from infy.graph import StateGraph, START, END, InMemorySaver
from infy import tool, create_agent
from infy.providers.openai import OpenAIChat

class State(TypedDict):
    messages: Annotated[list, lambda a, b: a + b]
    next_node: str

@tool
def search(query: str) -> str:
    """Search the web."""
    return f"Results for: {query}"

# Build the graph
graph = StateGraph(State)
graph.add_node("agent", call_model)
graph.add_node("tools", execute_tools)

graph.add_edge(START, "agent")
graph.add_conditional_edges(
    "agent",
    lambda state: "tools" if state.get("next_node") == "tools" else END,
    {"tools": "tools", END: END},
)
graph.add_edge("tools", "agent")

# Compile with checkpointing
checkpointer = InMemorySaver()
app = graph.compile(checkpointer=checkpointer)

# Run with thread persistence
result = app.invoke(
    {"messages": [{"role": "user", "content": "Search for infy"}]},
    config={"configurable": {"thread_id": "thread-1"}},
)
print(result)
