Runnable & Pipes

Everything in infy implements the Runnable protocol. Chains are built with the | pipe operator.

Runnable Protocol

The Runnable protocol defines four methods that every composable unit must implement:

MethodSignatureDescription
invoke(input, ctx?) → AnySynchronous execution
ainvokeasync (input, ctx?) → AnyAsynchronous execution
stream(input, ctx?) → Iterator[Any]Sync streaming
astreamasync (input, ctx?) → AsyncIterator[Any]Async streaming
The ctx parameter is optional in all methods. Pass a Context object to control tags, metadata, and concurrency.

Pipe Operator

The | operator composes two runnables into a Sequence:

python
from infy import Lambda

# These are equivalent:
chain = Lambda(str.upper) | Lambda(lambda x: x.strip())
chain = Lambda(str.upper).__or__(Lambda(lambda x: x.strip()))

# Execute
result = chain.invoke("  hello world  ")
print(result)  # "HELLO WORLD"

When you pipe a callable (function), it's automatically wrapped in a Lambda:

python
chain = Lambda(str.upper) | str.strip | Lambda(lambda x: x + "!")
result = chain.invoke("  hello  ")
print(result)  # "HELLO!"

Sequence

Sequence chains multiple runnables, passing the output of each as input to the next:

python
from infy import Sequence, Lambda

step1 = Lambda(lambda x: x + " world")
step2 = Lambda(str.upper)
step3 = Lambda(lambda x: x + "!")

chain = Sequence([step1, step2, step3])
result = chain.invoke("hello")
print(result)  # "HELLO WORLD!"

Parallel

Parallel executes multiple runnables concurrently on the same input, returning a dict of results:

python
from infy import Parallel, Lambda
from infy.core import Context

parallel = Parallel({
    "uppercase": Lambda(str.upper),
    "lowercase": Lambda(str.lower),
    "length": Lambda(len),
})

result = parallel.invoke("Hello")
print(result)
# {'uppercase': 'HELLO', 'lowercase': 'hello', 'length': 5}

Concurrency Control

Limit parallel execution with Context.max_concurrency:

python
from infy import Parallel, Lambda
from infy.core import Context

# At most 2 concurrent calls
ctx = Context(max_concurrency=2)

parallel = Parallel({
    "a": Lambda(lambda x: x),
    "b": Lambda(lambda x: x),
    "c": Lambda(lambda x: x),
})

result = parallel.invoke("test", ctx=ctx)

Lambda & AsyncLambda

Lambda wraps a sync function. AsyncLambda wraps an async function:

python
from infy import Lambda, AsyncLambda

# Sync
sync_step = Lambda(lambda x: x * 2)
print(sync_step.invoke(5))  # 10

# Async
async_step = AsyncLambda(lambda x: x * 2)
result = await async_step.ainvoke(5)  # 10

# Pipe with async
chain = Lambda(str.upper) | AsyncLambda(async_process) | Lambda(str.strip)

Context

Context carries execution metadata through the chain:

python
from infy.core import Context

ctx = Context(
    tags=["production", "v2"],
    metadata={"user_id": "123", "session": "abc"},
    max_concurrency=4,
)

# Merge contexts (useful for nested chains)
child_ctx = Context(tags=["v2", "debug"])
merged = ctx.merge(child_ctx)
print(merged.tags)  # ['debug', 'production', 'v2']
print(merged.metadata)  # {'user_id': '123', 'session': 'abc'}

coerce()

coerce() converts any callable, dict, or Tool into a Runnable:

python
from infy.core import coerce

# Function → Lambda
r = coerce(lambda x: x + 1)

# Dict → Parallel
r = coerce({"a": func_a, "b": func_b})

# Tool → Runnable
r = coerce(my_tool)

# Already a Runnable → returned as-is
r = coerce(Lambda(str.upper))

Complete Example

python
from infy import Lambda, Parallel, AsyncLambda, Sequence
from infy.core import Context

# Build a pipeline
pipeline = (
    Parallel({
        "name": Lambda(lambda x: x["name"].upper()),
        "age": Lambda(lambda x: x["age"] + 1),
        "tags": Lambda(lambda x: sorted(x.get("tags", []))),
    })
    | Lambda(lambda d: f"{d['name']} is {d['age']} years old. Tags: {', '.join(d['tags'])}")
    | str.strip
)

result = pipeline.invoke({
    "name": "alice",
    "age": 30,
    "tags": ["python", "llm", "infy"],
})
print(result)  # "ALICE is 31 years old. Tags: infy, llm, python"
