Messages

Four message types cover all LLM communication. No deep class hierarchies.

Message Types

TypeRoleKey Fields
HumanMessageUser inputcontent, name
AIMessageModel outputcontent, tool_calls, usage
SystemMessageSystem instructioncontent
ToolMessageTool resultcontent, tool_call_id

HumanMessage

Represents user input. Content can be a string or a list of content blocks:

python
from infy.messages import HumanMessage, TextBlock, ImageBlock

# Simple string content
msg = HumanMessage(content="What is infy?")

# Multimodal content
msg = HumanMessage(content=[
    TextBlock(text="Describe this image:"),
    ImageBlock(url="https://example.com/photo.jpg", mime_type="image/jpeg"),
])

# Access text
print(msg.text)  # "Describe this image:"
print(msg.type)  # "human"

AIMessage

Represents model output. May contain text, tool calls, or both:

python
from infy.messages import AIMessage, ToolCall, UsageMetadata

msg = AIMessage(
    content="I'll search for that.",
    tool_calls=[
        ToolCall(name="search", args={"query": "infy framework"}, id="call_1"),
    ],
    usage=UsageMetadata(input_tokens=50, output_tokens=20),
)

print(msg.text)            # "I'll search for that."
print(msg.has_tool_calls)  # True
print(msg.tool_calls[0].name)  # "search"
print(msg.usage.input_tokens)  # 50

SystemMessage

System-level instructions prepended to the conversation:

python
from infy.messages import SystemMessage

msg = SystemMessage(content="You are a helpful coding assistant.")
print(msg.text)  # "You are a helpful coding assistant."
print(msg.type)  # "system"

ToolMessage

Result of a tool execution, linked back to a specific ToolCall by ID:

python
from infy.messages import ToolMessage

msg = ToolMessage(
    content="{'temperature': 72, 'condition': 'sunny'}",
    tool_call_id="call_1",
    status="success",
)

print(msg.tool_call_id)  # "call_1"
print(msg.type)          # "tool"

AIMessageChunk

Used for streaming. Chunks merge additively via the + operator:

python
from infy.messages import AIMessageChunk, ToolCallChunk

# Accumulate streaming chunks
chunk1 = AIMessageChunk(content="Hello")
chunk2 = AIMessageChunk(content=" world")
chunk3 = AIMessageChunk(content="!")

full = chunk1 + chunk2 + chunk3
print(full.text)  # "Hello world!"

Tool Call Chunks

Tool call arguments stream incrementally and merge by index:

python
chunk1 = AIMessageChunk(
    content="",
    tool_call_chunks=[ToolCallChunk(name="search", args='{"q', index=0)],
)
chunk2 = AIMessageChunk(
    content="",
    tool_call_chunks=[ToolCallChunk(args='uery": "test"}', index=0)],
)

merged = chunk1 + chunk2
print(merged.tool_call_chunks[0].name)  # "search"
print(merged.tool_call_chunks[0].args)  # '{"query": "test"}'

# Convert to full AIMessage
msg = merged.materialize()
print(msg.tool_calls[0].name)  # "search"
print(msg.tool_calls[0].args)  # {'query': 'test'}

UsageMetadata

Token usage data, always present on AIMessage when available:

python
from infy.messages import UsageMetadata

usage = UsageMetadata(input_tokens=100, output_tokens=50)
print(usage.total_tokens)  # 150 (auto-calculated)

Complete Example

python
from infy.messages import (
    HumanMessage, AIMessage, SystemMessage, ToolMessage,
    ToolCall, ToolCallChunk, AIMessageChunk,
    TextBlock, ImageBlock, UsageMetadata,
)

# Build a conversation
messages = [
    SystemMessage(content="You are a helpful assistant."),
    HumanMessage(content="What's in this image?"),
    AIMessage(
        content="This is a sunset over the ocean.",
        tool_calls=[],
        usage=UsageMetadata(input_tokens=120, output_tokens=25),
    ),
]

# Stream and accumulate
chunks = [
    AIMessageChunk(content="The "),
    AIMessageChunk(content="image "),
    AIMessageChunk(content="shows "),
]
full_text = "".join(c.text for c in chunks)
print(full_text)  # "The image shows "
