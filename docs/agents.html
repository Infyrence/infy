Agents

Agents loop over model calls and tool executions. infy provides three flavors: sync, async, and graph-based.

Comparison

FactorySyncAsyncCheckpointingUse Case
create_agentYesNoNoSimple scripts, CLI tools
create_async_agentNoYesNoWeb servers, async apps
create_graph_agentYesNoYesStateful workflows, HITL

create_agent

A simple while-loop agent. Returns a sync callable:

python
from infy import tool, create_agent
from infy.providers.openai import OpenAIChat

@tool
def search(query: str) -> str:
    """Search the web."""
    return f"Results for: {query}"

@tool
def calculator(expression: str) -> str:
    """Evaluate a math expression."""
    return str(eval(expression))

agent = create_agent(
    OpenAIChat("gpt-4o"),
    tools=[search, calculator],
    system_prompt="You are a helpful assistant.",
    max_iterations=10,
    parallel_tools=True,
)

# Call with a string
result = agent("What is 42 * 17?")

# Or call with a message list
from infy.messages import HumanMessage, SystemMessage
result = agent([
    SystemMessage(content="You are a math tutor."),
    HumanMessage(content="What is 42 * 17?"),
])

print(result.response.text)
print(f"Iterations: {result.iterations}")
print(f"Tool calls: {result.tool_calls_made}")
print(f"Messages: {len(result.messages)}")

create_async_agent

Async version using asyncio.gather for parallel tool execution:

python
import asyncio
from infy import tool, create_async_agent
from infy.providers.openai import OpenAIChat

@tool
async def fetch_weather(city: str) -> str:
    """Get weather for a city."""
    # Simulate async API call
    await asyncio.sleep(0.1)
    return f"Weather in {city}: sunny, 72F"

@tool
async def fetch_news(topic: str) -> str:
    """Get latest news on a topic."""
    await asyncio.sleep(0.1)
    return f"News about {topic}: infy framework released!"

agent = create_async_agent(
    OpenAIChat("gpt-4o"),
    tools=[fetch_weather, fetch_news],
    system_prompt="You are a helpful assistant.",
)

async def main():
    result = await agent("What's the weather in SF and latest AI news?")
    print(result.response.text)

asyncio.run(main())

create_graph_agent

Graph-based agent with checkpointing, state persistence, and human-in-the-loop support:

python
from infy import tool, create_graph_agent
from infy.graph import InMemorySaver
from infy.providers.openai import OpenAIChat

@tool
def search(query: str) -> str:
    """Search the web."""
    return f"Results for: {query}"

checkpointer = InMemorySaver()

agent = create_graph_agent(
    OpenAIChat("gpt-4o"),
    tools=[search],
    system_prompt="You are a helpful assistant.",
    checkpointer=checkpointer,
    interrupt_before=["tools"],  # Pause before tool execution
)

# First invocation
result = agent.invoke(
    {"messages": [{"role": "user", "content": "Search for infy"}]},
    config={"configurable": {"thread_id": "thread-1"}},
)
print(result)

# Resume (continues from checkpoint)
result2 = agent.invoke(
    {"messages": [{"role": "user", "content": "Tell me more"}]},
    config={"configurable": {"thread_id": "thread-1"}},
)

# Inspect state
state = agent.get_state(config={"configurable": {"thread_id": "thread-1"}})
print(state.values)
print(state.next)

AgentResult

All agents return an AgentResult dataclass:

python
from infy.agents import AgentResult

@dataclass
class AgentResult:
    messages: list[Message]      # Full conversation history
    response: AIMessage          # Final model response
    iterations: int              # How many loop iterations ran
    tool_calls_made: int         # Total tool calls executed

Complete Example

python
from infy import tool, create_agent
from infy.providers.openai import OpenAIChat

@tool
def get_stock_price(symbol: str) -> str:
    """Get the current stock price for a ticker symbol."""
    prices = {"AAPL": 178.50, "GOOGL": 141.80, "MSFT": 378.90}
    return f"{symbol}: ${prices.get(symbol, 'N/A')}"

@tool
def analyze_sentiment(text: str) -> str:
    """Analyze the sentiment of text."""
    positive_words = ["good", "great", "bullish", "rise", "profit"]
    score = sum(1 for w in positive_words if w in text.lower())
    if score > 2:
        return "Positive"
    elif score > 0:
        return "Neutral"
    return "Negative"

@tool
def search_news(query: str) -> str:
    """Search for recent news."""
    return f"Latest news about {query}: Market trends look promising."

agent = create_agent(
    OpenAIChat("gpt-4o"),
    tools=[get_stock_price, analyze_sentiment, search_news],
    system_prompt=(
        "You are a financial analyst assistant. "
        "Use tools to get stock prices, analyze sentiment, and search news. "
        "Provide concise, data-driven analysis."
    ),
    max_iterations=15,
)

result = agent("Analyze AAPL: get the price, search for recent news, and analyze the sentiment of the news.")

print("Response:", result.response.text)
print(f"Tool calls: {result.tool_calls_made}")
print(f"Iterations: {result.iterations}")
